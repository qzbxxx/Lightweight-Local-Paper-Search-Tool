# 📚 Local Literature Retrieval Agent (本地文献检索智能体)

基于 Python 与大语言模型（LLM）构建的轻量级本地学术文献检索工具，其中模型调用是基于 DeepSeek。无需配置复杂的本地向量数据库，采用**“本地零成本粗排 + 大模型极简精排”**的级联架构，支持一键打包为独立桌面程序。

---

## ✨ 核心亮点

- **开箱即用**：独立 exe 运行，无需在目标电脑配置复杂的 Python 或深度学习环境。
- **极致省钱（低 Token 消耗）**：
  - **粗排阶段**：通过本地 Python 关键词算法秒级初筛 Top-5，**不消耗任何大模型 Token**。
  - **精排阶段**：智能正则清洗 PDF，剔除作者、机构、版权等无用杂质，仅将精炼摘要（Abstract）送入大模型。单次查询成本低至 **3000 Tokens**。
- **敏感信息分离**：API Key 完全剥离在外部 `api.txt`，界面清爽无干扰，更换 Key 仅需修改文本文件。
- **热更新感知**：放入新文献后无需重启软件，点击界面的“🔄 刷新文献库”即可快速载入。

## 📂 目录结构规范

为了保证软件正常工作，程序目录结构需保持如下规范：

```text
📁 Paper_Agent/
├─────api_service.py                  # 大模型调用 Prompt 设置
├─────main.py                         # 软件的主界面入口
├─────pdf_loader.py                   # 负责扫描 文献 文件夹并提取纯净摘要
├─────📁 dist
|     ├── Paper Agent.exe             # 编译后的主程序（双击直接运行）
│     ├── api.txt                     # 大模型 API 配置文件
│     └── 📁 文献                    # 存放待检索 PDF 论文的专用文件夹
